## Getting Started

### Prerequisites
- Node.js (LTS)
- Python 3.x + pipenv

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Runs at `https://gracezawadi.vercel.app/`

### Backend

```bash
cd backend
pipenv install
pipenv run python app.py
```

Runs at `https://my-portfolio-backend-xv6u.onrender.com`
